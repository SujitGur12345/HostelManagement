Project Setup
Clone the Repository
git clone https://github.com/SujitGur12345/HostelManagement.git
cd HostelManagement (Navigate to the project / open the project )

Database Configuration

After cloning, update only the database username and password in:

src/main/resources/application.properties

spring.datasource.username=YOUR_DB_USERNAME
spring.datasource.password=YOUR_DB_PASSWORD


All other properties should remain unchanged.
